# 哔哔啵啵 · 动静工坊（syllable-voice）

把一句话变成小人说话声，可调音色、可导出 WAV。纯前端、零依赖、零素材、零网络请求。

引擎派生自 [hakihakii/bibibobo](https://github.com/hakihakii/bibibobo)（MIT，© 2026 hakihakii / Lumoswitch），保留原始版权与许可声明，详见 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`。

## 启动

浏览器不允许 `file://` 下加载 ES Module，所以需要一个本地静态服务器（任选其一）：

```bash
# 方式一：Python（推荐，系统自带即可）
# 在仓库根目录执行
python -m http.server 5173
# 打开 http://127.0.0.1:5173

# 方式二：Node
npx --yes serve . -l 5173

# 方式三：VS Code 装 Live Server，右键 index.html → Open with Live Server
```

`npm start` 等价于方式一。

## 文件结构

```
syllable-voice/
├── index.html              页面骨架（语义化标签，无内联逻辑）
├── package.json            仅声明 type:module 与 start 脚本，无运行时依赖
├── LICENSE                 MIT 全文（含上游版权行）
├── THIRD_PARTY_NOTICES.md  上游项目、修改点与素材说明
├── assets/
│   └── style.css           设计令牌 + 布局 + 控件 + 响应式（约 400 行）
└── src/
    ├── engine.js           合成引擎：振荡器、滤波器、包络、语气、效果链、WAV 封装
    ├── corpus.js           语料包 core-zh@1.1.0：13 口型 / 5 起音 / 7 语气 / 5 音阶
    ├── presets.js          7 套官方音色（2 套原版兼容 + 5 套风格）
    └── app.js              界面状态、控件生成、渲染、播放、导入导出、分享
```

数据与算法是分开的：`engine.js` 只认 `voice` 与 `corpus` 两个对象，换语料/换音色都不需要改代码。

## 已实现

**合成链路**
- 文字 → 切句（按标点）→ 切字（汉字一声、连续英数一声）→ 哈希映射音高/口型/起音 → 双共振峰合成 → 效果链 → 16bit 单声道 WAV。
- polyBLEP 抗混叠锯齿波，以及方波 / 脉冲 / 三角三种可选波形。
- 五种起音（无 / 摩擦 / 低爆破 / 高爆破 / 鼻音）、双元音共振峰滑动、字间重叠。
- 效果链：混响（4 梳状 + 全通）、低通、位深压缩、软限幅；全部离线渲染，结果可复现。
- 标点管语气：问号、反问（含"吗/呢/什么"等）、感叹、省略号、波浪号拖长、括号耳语。

**音色系统**
- 6 层参数面板（音源 / 口型 / 音高 / 节奏 / 语气 / 效果）共 19 项，改动即时重算（约 15–40 ms）。
- 7 套预设；"经典"两套走原版 5 口型算法，可和"2.0"新语料直接 A/B。
- 随机音色、还原预设、改动即试听（取前 5 个音节的短片段循环）。
- 音色 JSON 导入 / 导出、分享链接（`#v=` base64url，约 700 字符，打开即还原，含 hashchange 热更新）。
- 导入做字段级校验与数值 clamp，缺失字段回落到默认值，坏数据不会白屏。

**界面**
- 深色工作室风格，主色沿用原版示波器的 `#7CF5C6`。
- 桌面双栏 + 右侧吸顶滚动；≤980px 自动拆成单栏，声线面板紧跟波形（用 `display:contents` 重排，不复制 DOM）。
- ≤620px 的按钮、统计、字号单独适配；无横向溢出。
- 波形用对称包络绘制（peak per column），支持 DPR 高清与窗口重绘。
- 键盘：`Ctrl/⌘ + Enter` 直接说；控件均可 Tab 聚焦，focus ring 可见。
- 示例台词一键换上（疑问 / 感叹 / 省略 / 耳语 / 拖长 / 中英混）。

**已知修复**
- 空文本、纯标点不再产出 0.4 秒静音 WAV（上游行为），而是禁用按钮并提示。
- 音高与口型索引解耦后，"大肥鱼"从 5 种音节提升到 13 种（同句实测 4 → 13）。

## 暂未实现

| 项 | 现状 | 说明 |
|---|---|---|
| 与上游逐样本一致（P0 验收） | 未做 | 本 demo 重写了振荡器标定与总线，听感接近但 WAV 不与上游 MD5 相同；正式版应先做基线复刻再叠加 |

| 音色市场 / 云同步 | 无 | 现在靠 JSON 与链接分享，无后端 |
| DSH 插件（P4） | 未做 | 需要 `shell.overlay` 槽位与 `cordis.patch.yml`，本 demo 是网页形态 |
| 长文本分段 | 上限 200 字 | 未做流式合成与分段导出 |
| 音阶自定义编辑 | 只读预设音阶 | 可导入 preset 里的任意音阶，但界面无编辑器 |
| 波形交互 | 只读 | 不能框选/循环播放片段 |
| 移动端 Safari 静音键 | 未真机复测 | 已用 `<audio>` + Blob（上游为此改过），但仍需真机验证 |
| 无障碍完整度 | 基础 | 有 label/aria/focus，未做屏幕阅读器全流程测试 |
| 录音 / 导出 MP3 | 无 | 只导出 16bit WAV |
